# PackMate - Backpacker Packing List

A simple mobile web app for backpackers.
Make reusable packing lists per trip type, check items, track packing progress, create custom trips, and manage settings.

## Features

* Home page with Trip Types Overview
* 5 Trip Types - Beach Trip, Mountain Hike, City Tour, Camping, International Trip
* Packing List Details with Categories and Progress Bar
* Add, Edit, Delete Items
* Create Custom Trip / Custom List
* Search Items
* Save Lists - Auto-save with localStorage
* Settings - Dark Mode, Sound, Font Size, Reset All, Clear Checked
* Reusable Lists - Use same list for every trip

## How to Install and Run

1. Open Live Demo in your browser:
https://packmate-backpacker-packing-list-2f.vercel.app
2. Or download the code, open index.html in your browser
3. On mobile Chrome, tap 3 dots > Add to Home Screen to install as app
